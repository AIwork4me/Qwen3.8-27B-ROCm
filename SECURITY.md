# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately**: use GitHub's
[private vulnerability reporting](https://github.com/AIwork4me/Qwen3.8-27B-ROCm/security/advisories/new)
(Security tab → "Report a vulnerability"), or contact the repository owner
directly. Do **not** open a public issue for a security report.

## Scope

This repository's scripts, configs, and CI. The model artifacts
([Qwen/Qwen3.8-27B](https://modelscope.cn/models/Qwen/Qwen3.8-27B)) belong
to Qwen and are governed by their own license; this repository does not
redistribute them.
