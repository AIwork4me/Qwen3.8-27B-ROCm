**Goal:** Build vLLM from source for ROCm on gfx1151, fetch Qwen3.8-27B BF16 from ModelScope, and validate serving (text, MTP, vision, context) with receipts — the first serving path of the project.

**Architecture:** Reuse the proven Muse-Glimmer vLLM-on-gfx1151 recipe (TheRock torch from the AMD nightly index, host ROCm toolchain for CMake, editable source build with pinned commit, amdsmi shim) adapted to upstream vLLM main which natively registers `Qwen3_5ForConditionalGeneration` + `Qwen3_5MTP` (spike A, receipt `docs/results/spike/vllm.md`). Model artifacts come from ModelScope (huggingface.co is TCP-unreachable on this host) with manifest-driven size+SHA256 verification. Every host-side outcome — success or failure — lands in `docs/results/rocm-7.14/` as evidence.

**Tech Stack:** bash, uv (Python 3.12), TheRock PyTorch (gfx1151 nightly index), vLLM main @ pinned commit, ModelScope API, pytest.

**Spec:** `docs/superpowers/specs/2026-08-16-qwen3.8-27b-rocm-design.md`
**Spike findings that gate this plan:** `configs/spike-findings.json` (paths.vllm=supported), `docs/results/spike/vllm.md`, `docs/results/spike/quant-kv.md`.

`scripts/02-fetch-model.sh`:

```bash
#!/usr/bin/env bash
# Fetch the Qwen3.8-27B BF16 artifact set from ModelScope into models/.
# Manifest-driven: every file is verified against configs/artifact-manifest.json
# (size + SHA256) after download; verified files are skipped on re-run.
# Resumable: partial downloads continue with -C -.
#   MODEL_DEST=/path      override destination
#   NCONNS=N              parallel shard downloads (default 6)
#   MS_ENDPOINT=https://modelscope.cn   override mirror
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
cd "$ROOT"
command -v python3 >/dev/null 2>&1 || { echo "ERROR: python3 required" >&2; exit 1; }
command -v curl >/dev/null 2>&1 || { echo "ERROR: curl required" >&2; exit 1; }

MANIFEST="configs/artifact-manifest.json"
DEST="${MODEL_DEST:-models/Qwen3.8-27B}"
MS_ENDPOINT="${MS_ENDPOINT:-https://modelscope.cn}"
NCONNS="${NCONNS:-6}"

REPO="$(python3 -c 'import json;print(json.load(open("'"$MANIFEST"'"))["sets"]["bf16"]["repository"])')"
REV="$(python3 -c 'import json;print(json.load(open("'"$MANIFEST"'"))["sets"]["bf16"]["revision"])')"

mkdir -p "$DEST"

python3 - "$MANIFEST" "$DEST" "$MS_ENDPOINT" "$REPO" "$REV" "$NCONNS" <<'PY'
import hashlib, json, os, subprocess, sys
from concurrent.futures import ThreadPoolExecutor

manifest, dest, endpoint, repo, rev, nconns = sys.argv[1:7]
files = json.load(open(manifest))["sets"]["bf16"]["files"]
base = f"{endpoint}/api/v1/models/{repo}/repo"
os.makedirs(dest, exist_ok=True)

def verified(path, size, sha):
    f = os.path.join(dest, path)
    if not os.path.isfile(f) or os.path.getsize(f) != size:
        return False
    h = hashlib.sha256()
    with open(f, "rb") as fh:
        for chunk in iter(lambda: fh.read(1 << 22), b""):
            h.update(chunk)
    return h.hexdigest() == sha

def fetch(item):
    path, size, sha = item["path"], item["size_bytes"], item["sha256"]
    if verified(path, size, sha):
        print(f"  skip (already verified): {path}", flush=True)
        return path, True
    url = f"{base}?FilePath={path}&Revision={rev}"
    out = os.path.join(dest, path)
    for attempt in range(1, 4):
        r = subprocess.run(["curl", "--fail", "--location", "--retry", "3",
                            "--retry-all-errors", "--connect-timeout", "20",
                            "--continue-at", "-", "--output", out, url])
        if r.returncode == 0 and verified(path, size, sha):
            print(f"  ok: {path}", flush=True)
            return path, True
        print(f"  retry {attempt}/3: {path} (rc={r.returncode})", flush=True)
    print(f"  FAIL: {path} — size/sha256 mismatch after 3 attempts", flush=True)
    return path, False

with ThreadPoolExecutor(max_workers=int(nconns)) as ex:
    results = list(ex.map(fetch, files))

failed = [p for p, ok in results if not ok]
if failed:
    print(f"ERROR: {len(failed)} file(s) failed verification: {failed}", file=sys.stderr)
    sys.exit(1)
total = sum(f["size_bytes"] for f in files)
print(f"OK: {len(files)} files verified ({total/2**30:.1f} GiB) in {dest}")
PY
```

```bash
#!/usr/bin/env bash
# Validate the vLLM server (text path + MTP) and write receipts.
# Assumes scripts/03-serve-vllm.sh is already running in another terminal
# (or starts it itself with --mtp for the second pass).
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
BASE_URL="${BASE_URL:-http://127.0.0.1:8000}"
RECEIPT="$ROOT/docs/results/rocm-7.14/vllm-validation.md"
mkdir -p "$(dirname "$RECEIPT")"

health() { curl -fsS --max-time 10 "$BASE_URL/health" >/dev/null && echo ok; }
chat() {  # chat <json-file> -> response json on stdout
    curl -fsS --max-time 600 "$BASE_URL/v1/chat/completions" \
        -H 'Content-Type: application/json' -d @"$1"
}

echo "# vLLM validation receipts — $(date -u +%Y-%m-%dT%H:%MZ)" > "$RECEIPT"
{
  echo "## Boot"
  echo "- server: $BASE_URL"
  echo "- health: $(health)"
  echo
  echo "## Greedy smoke"
} >> "$RECEIPT"

cat > /tmp/q38-greedy.json <<'EOF'
{"messages": [{"role": "user", "content": "Reply with exactly: OK"}],
 "temperature": 0, "max_tokens": 512}
EOF
python3 - "$RECEIPT" <<'PY' < <(chat /tmp/q38-greedy.json)
import json, sys
receipt = sys.argv[1]
resp = json.load(sys.stdin)
msg = resp["choices"][0]["message"]
content = msg.get("content") or ""
reasoning = msg.get("reasoning_content") or ""
with open(receipt, "a") as f:
    f.write(f"- finish_reason: {resp['choices'][0]['finish_reason']}\n")
    f.write(f"- reasoning tokens (hidden): {len(reasoning)}\n")
    f.write(f"- content tail: {content[-80:]!r}\n")
    f.write(f"- greedy OK present: {'OK' in content}\n")
PY
# MTP pass is orchestrated manually in Task 5 steps: restart server with --mtp,
# re-run the same greedy prompt, append "## MTP" section with acceptance-rate
# evidence from the server log (grep -i 'accept' over the mtp server log tail).
echo "(run MTP pass per plan Task 5 Step 3b, then finish receipt)"
```

1. `nohup bash scripts/03-serve-vllm.sh > /tmp/vllm-serve.log 2>&1 &` — poll `curl -s http://127.0.0.1:8000/health` until ok (weight load of ~49.8 GiB takes minutes; record boot wall time, and vLLM's reported KV-cache blocks / max concurrency from the log: `grep -iE 'KV cache|Maximum concurrency|model loading took' /tmp/vllm-serve.log`).
2. `bash scripts/04-validate-vllm.sh` — record greedy result.
3. Kill server; relaunch with `--mtp`; repeat greedy; append `## MTP` section with server-log acceptance-rate lines (`grep -iE 'acceptance|spec' /tmp/vllm-serve-mtp.log | tail -5`).
4. Context probe (`## Context probe`): with baseline server, POST a `/v1/chat/completions` with a ~2000-token filler prompt and `max_tokens: 32` (functional only — the full context-capacity matrix belongs to the benchmark plan); record the response time and any boot-time reduction of max len you had to make (if 262144 fails to allocate, lower to 131072/98304 and record the failure line from the log verbatim — that IS the finding).
